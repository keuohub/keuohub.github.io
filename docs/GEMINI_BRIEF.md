# 给 Gemini 的项目简报

这份是给你的完整背景。读完你应该清楚：我们在做什么生意、用户是谁、哪些已经做好了、剩下的视觉归你、你能动到什么程度。

**我不给你设审美红线。** 字体、配色、间距、圆角、装饰、动效节奏、布局微调，全部由你判断。唯一的判断标准写在第十一节。

不用回复确认，也不用问"这样可以吗"。直接改，改完刷新页面就是成品。

---

## 一、我们在做什么

**一句话：做一批能上架卖的 H5 测试链接，一套测试一条链接。**

买链接的人把它投到小红书、抖音、快手、视频号上。刷到的人点开、答几道题、看到结果，然后把结果截图发出去、转到群里。

这个生意里有一个残酷的事实：**结果页那一张截图，就是产品本身。**

用户不会因为页面动效炫就转发，他转发是因为"这句话就是我"、"这个标签发出去有面子"。所以：

- 结果页最好能在手机竖屏下一屏放得下，不用滑就能截图
- 截出来的图要好看、要干净、要能当封面用
- 页面长得越像广告，用户越不愿意转发

你手上做的不是"美化一个网页"，是在做**用户愿意主动传播的那张图**。怎么做到，你比我有想法。

---

## 二、用户是谁，在什么场景下用它

- 在刷短视频、刷笔记的间隙点进来的，一只手持机，竖屏
- 前 3 秒决定要不要继续
- 答完立刻截图，发笔记、发朋友圈、发群，或者直接转发给朋友玩
- 年龄跨度大：小红书是 18-35 岁女性为主，抖音快手更全年龄更下沉，视频号有相当比例的长辈

不同平台的人群差别很大，这也是为什么同一套测试在三平台要做出力度差别。怎么做出差别，听你的。

## 三、已经做好的部分（我负责的，你不用管）

- 答题流程：点选项自动进下一题、可返回上一题、进度自动保存、维度加权算结果
- 五套测试的题目、结果标签、金句、解读、分享文案（内容已定稿，你可以提意见，但改动需要我同步）
- 分享图渲染：点「保存结果图」生成 PNG，尺寸按平台自动切换（小红书 900×1200，其余 900×1600）
- 分享按钮：调系统分享，或自动复制文案

**关键点：网页和分享图共用同一套变量。** 你改一次配色或换一张底图，页面和分享出去的图同时变，不用做两份。

每个文件里已经按平台分好段落，我在里面铺了一版很粗的基线，只当占位符看。把它做成你觉得对的样子。

### 2. 背景图（建议做，不是必须）

放 `assets/themes/<测试编号>/<平台>.png`，然后在主题文件里加两行：

```css
--bg-image: url("/assets/themes/love-style/xhs.png");
--bg-image-scrim: 0.86;
```

- 路径必须以 `/` 开头，相对路径加载不到
- `--bg-image-scrim` 是压在图上的遮罩浓度，0 到 1，用来保证文字可读。数值你定
- 竖版 1080×1920 或 1200×1600，构图自己把握，注意标题会落在上三分之一
- 同一张图会同时用在网页背景和分享图上

## 五、这些都是你的地盘

### 1. 主题文件里不只能改变量，任何 CSS 都能覆盖

主题文件是最后加载的，优先级最高。你可以在里面写 `.result-tag { ... }`、`.btn { ... }`、`.option { ... }` 这类覆盖，直接改掉我写的样式，不用动我的文件。

想做只有你这套测试才有的排版，用 `body[data-test='love-style']` 开头写选择器就行。

### 2. 想加视觉元素，用伪元素和背景层做，不用改 HTML

分隔线、印章、编号、撕边、边框、纹理、纸感、光斑、暗角，都可以用 `::before` / `::after` 和多层 `background` 加进去。

如果你觉得需要真正新增 DOM 元素才能表达（比如想要一个装饰插画位），告诉我，我加。

### 3. 动效节奏你定

页面切换、标签出现、按钮反馈的时长和曲线都在 `src/styles.css` 里。想改先告诉我，我改；或者你在主题文件里用同样的选择器覆盖，也生效。

### 4. 结构也能提

封面页、答题页、结果页的信息顺序是现在的样子，但如果你觉得某个页面从设计角度就是别扭，提出来。结构我改，你负责说服我。

### 5. 分享图的排版，提需求给我

分享图是用 canvas 画的（`src/card.js`），CSS 管不到，这是唯一的例外。但你可以随便提要求，比如"标签下面加一条手绘下划线"、"底部做成票根撕边"、"四种结果用四种底纹"、"加一个二维码位"。说清楚想要什么，我来实现。

## 九、页面结构现状

结果页从上到下：

1. 核心标签 —— 最大字号
2. 点睛金句
3. 卡片区：数据锚点 + 解读文字 + 副标签（有才出现）+「保存结果图」文字按钮
4. 底部两个按钮：分享给朋友（主）、重新测试（次）

封面页：题量时长 → 大标题 → 副标题 → 引导语 → 开始测试按钮。

答题页：顶部进度条 + 题号，题干，四个选项。点选项自动进下一题。

这些顺序可以调整，觉得该换就提。

## 十、现成的旋钮

下面是代码里已经接好的变量，改它们是最快的路径，但它们**不是边界**，只是现成的旋钮。你也可以不用它们，直接在主题文件里写具体样式。

| 变量 | 作用 |
| --- | --- |
| --bg | 页面底色。**这一条是技术限制**：分享图的底色会读它，所以必须是纯色，写渐变的话分享图会退回默认色。想要丰富的底请用背景图 |
| --bg-glow | 页面顶部光晕 |
| --card | 卡片底色 |
| --card-line | 卡片描边 |
| --ink / --ink-soft | 主文字 / 次要文字 |
| --accent / --accent-ink | 强调色 / 它上面的文字 |
| --shadow | 卡片投影 |
| --font-title / --font-body | 标题字体 / 正文字体（外部字体可以用 `@import`，注意加载体积） |
| --title-weight | 标题字重 |
| --tag-size | 结果页大标签字号 |
| --radius | 圆角 |
| --pad | 页面左右内边距 |
| --bg-image / --bg-image-scrim | 背景图 / 遮罩浓度 |

加自己的新变量（比如装饰元素专用色）也完全可以。

## 十一、唯一的判断标准

**目标用户看到这张图，会不会愿意存下来、发出去。**

愿意，就是对的。不愿意，再精致也是白做。

我没有禁忌清单，也不打算给你列一个。你如果觉得某个效果能提高转发意愿，就大胆用；用完之后打开手机模拟器看一眼一屏能不能放下、文字会不会被糊掉，就够了。

## 十二、交完自己看一眼

这几条是技术验收，不是审美要求：

1. 结果页在手机竖屏下一屏放得下，不用滑就能截图（这是这个生意的前提）
2. 每个平台版本单独看，大标签和解读文字都清楚可读
3. 点一次「保存结果图」，图上的文字没有被背景图吃掉
4. 按钮点击区域不小于 48px，手机上点得准

审美上好不好，你自己心里那杆秤说了算。
