# 收钱怎么做（当前方案）

## 用户看到的流程

点开链接 → 免费做完全部题 → 结果页锁住（标签只露两个字，解读打码）→ 输激活码 → 完整结果 + 能保存分享图。

题目全部免费是有意的：用户投入了 10 道题，看到「热烈●●●」这种半截结果，比做一半就被拦住更愿意掏钱。

## 三步就能开卖

**第一步，准备收款码**

把你的微信或支付宝收款码存成 `assets/pay/收款码.png`。没放图的话付款面板会显示一个虚线框和提示文字。

**第二步，生成卡密**

```bash
npm run codes -- 200              给所有测试用的通用码
npm run codes -- 200 love-style   只给恋爱测试用
```

会生成两个文件：

- `codes-明文.csv`：卡密原文，**你自己留着发货，绝对不要上传或公开**
- `codes.json`：只有哈希值，放进项目里随站点部署，别人下载也还原不出卡密

**第三步，卖一个发一个**

从 CSV 里拿一个码发给买家。他打开链接答题，结果页输入这个码就解锁了。

## 在哪收钱

| 渠道 | 怎么操作 | 适合 |
| --- | --- | --- |
| 淘宝 / 闲鱼 / 微店 | 挂个商品，买家拍下后你发码。码可以导进淘宝的自动发货，能做到拍下秒发 | 最省心，平台代收款，不用自己搞支付 |
| 微信 | 买家扫码付款，你在微信里手动把码发过去 | 量小够用，量大会累 |
| 发卡平台 | 把码批量导入平台，用户付款后系统自动发码 | 量起来了用，全程无人值守 |

## 现在的局限（这点必须知道）

**「一码一用」目前是软的。**

码用过之后，使用记录只存在用户自己那台设备的浏览器里。他换台手机、换个浏览器，同一个码还能再用一次。他要是把码发到群里，别人也能用。

卡密本身是安全的——`codes.json` 里只有 SHA-256 哈希，别人下载了项目文件也还原不出码。防不住的是「同一个码被多人用」。

要做到严格一码一用、用过即废、还能看到每个码什么时候被谁用了，必须有一个后端来记账。**这套后端已经写好了**，在 `worker/` 目录，用的是 Cloudflare Worker + D1：

- 免费额度：每天 10 万次写入、500 万次读取，卖一单只消耗一次写加一次读
- 一次导入一万个码也不会超（KV 方案每天只给 1000 次写入，导一万个码会直接失败，所以没用 KV）
- 你只需要注册一个 Cloudflare 账号，然后按 `worker/README.md` 走六步
- 部署完把地址填进 `src/config.js` 的 `endpoint`，付费墙就切到真核销了

## 微信支付直跳这个事

做不到，短期内也绕不过去。网页里调起微信付款需要三样东西同时具备：

1. 营业执照开出来的微信商户号（个人申请不了）
2. 已备案的域名
3. 后端做支付签名（签名放前端等于把密钥公开）

等你注册了个体工商户，这三样才有得谈。在那之前，收款就是上面那张表的三种方式。

## 价格怎么改

已经在 `src/config.js` 里按平台配好了：

| 平台 | 价格 |
| --- | --- |
| 小红书 | 9.9 |
| 视频号 | 6.9 |
| 抖音 / 快手 | 1.9 |

改 `PRICES` 那个对象就行。同一套测试在小红书卖 9.9、抖音卖 1.9 是合理的，链接本来就按平台分开了。
