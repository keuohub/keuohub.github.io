## 踩过的坑，别再踩

- 分享图不能只做「快照」：改颜色必须改 CSS 变量，因为 canvas 和网页读的是同一套，硬编码颜色会导致两边不一致
- 锁定态不能用 CSS 模糊：模糊只是视觉遮住，右键查看源码就能拿到原文，必须在 DOM 里就打码
- 背景图的颗粒块不能小于 4px：小颗粒会让 PNG 几乎无法压缩，体积从 300KB 飙到 1MB，肉眼却看不出差别
- 图片路径必须以 `/` 开头：CSS 变量里的相对路径在 canvas 里会解析错
- 主题选择器是 `body[data-test='xxx'][data-theme='yyy']`，没有 `data-platform` 这个属性
